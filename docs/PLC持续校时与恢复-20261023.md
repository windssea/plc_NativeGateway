# PLC 持续校时与恢复验证

本轮处理 PLC 的持续校时与恢复；Hub 数据库问题转交 [Hub 问题交接](Hub入库问题交接-20261023.md)。PLC 应用仍为已编译下载的 `native-0.5.0`，本轮没有修改 IEC/HMI 应用、没有重新编译或下载。

## 持续时间源

联调机 `192.168.0.5` 新增 Docker 容器 `nativegateway-ntp`，UDP 123，仅绑定联调网卡，重启策略 `unless-stopped`。构建和配置见 [NTP 部署说明](../deploy/ntp/README.md)。chrony 4.6.1 使用 `-x`，不修改宿主机时钟；`local stratum 10` 跟随与 Hub 同机的时间基准。

这是局域网共同时间源，不能证明宿主机已获得可溯源 UTC。Docker Desktop 和主机需要保持运行；生产现场优先接入持续校准的现场 NTP，而非依赖个人电脑。

2152 的 WBM 已保存 NTP 服务器 `192.168.0.5`、Active、64 秒轮询；WBM 时区 UTC+00:00。NativeGateway 的 `Bootstrap.UtcOffsetMinutes` 已通过现有 HMI 保存事务设为 **0** 并持久化。原先手动写本地墙上时间时的 480 仅适用于历史联调，不得在 UTC/NTP 环境沿用。

## 安全切换和整机重启

先以同一网关标识进入维护，保留 50 台/250 点；临时修改一处采集周期，使新平台遥测暂停，等待已有队列清空。维护窗口内将控制器系统从错误的当地墙上时间调整到 UTC，并保存网关零偏移。大幅跳时不能在正常上报期间直接执行。

随后实际重启控制器 OS，观察到 RSC 端口中断及恢复，boot21 → **boot22**。从发起到验证原生应用恢复约 **217.15 秒**，该时间包含 OS、网络及持久化恢复，不是每次重启的性能承诺。

恢复时 MQTT 已连接，时差约 **-0.142 秒**；同一网关标识、维护模式、本地修改标记、250 点及保存的平台备份均保留，持久化无错误。再交还 Hub，精确恢复此前 v9 平台点表，撤销临时采集周期。之后真实 Hub 发布 v10/v11 调整并还原组批周期，最终 v11，组批 1000 ms，250 点采集和上报均为 5000 ms。

重启脚本为 `tests/continuous_time_verify.py`，各阶段有前提检查，不应批量无条件运行。它会真实修改维护状态、时钟偏移，并在 `reboot` 阶段重启 PLC，仅用于已授权的隔离联调。

## 短时连续观察

`tests/plc_time_stability.py --seconds 480 --restart-ntp` 只读检查 PLC 250 点真实样本、单调采集年龄、时钟、MQTT 原始报文、真实 Hub 回执和每 10 秒的资源记录；其中明确重启的只有联调 NTP 容器，不重启 PLC、broker 或 mock，也不发布配置、伪造业务回执。

最终数值与判定见 [精简实测证据](../tests/validation/continuous-time-20261023.json)。NTP 容器重启后须看到新的客户端请求及持续正确的 PLC 时间，不能只以容器 healthy 或 WBM Active 判定同步成功。Hub 回执延迟单独统计，不作为 Hub 已修复的结论。

实测连续 **485.27 秒**，29 次全点读取、16 条心跳、374 条数据报文，MQTT 覆盖全部 250 点；点位数值和质量全部符合 mock 预期。最大单调采集年龄 5.08 秒，时钟差 -1.118～-0.078 秒（包含秒级 RTC 量化和读取耗时），CPU 36%～72%，实际内存始终 69%，IEC 程序/数据占用为 10%/46%。无意外 boot 变化、丢弃、无效回执、持久化错误或契约错误。NTP 容器重启后重新累计 5 次请求，丢弃为 0。

真实 Hub 收到并确认观察窗口内 366 个唯一批次；最大观测回执延迟约 16.48 秒，窗口结束时还有 8 个已观察批次尚未在该窗口获得回执，不能将其宣称全部入库或丢失。PLC 队列采样峰值 13/16，表明仍有后端背压，虽然采集继续正常，也需要 Hub 项目继续处理。

WBM 重载已确认 UTC 和保存的 NTP 条目；HMI 页面可以导航到 NativeGateway 标题，但此次浏览器截图调用超时，未取得新的画面验证，不把它记作 HMI 可用性验收通过，也不能据此归因为 PLC 故障。

此轮为维护恢复与短时验证，不是已取消的 8 小时长测，不能证明无限期稳定。16 批遥测队列仍为 RAM，断电前未确认批次没有持久化承诺。
