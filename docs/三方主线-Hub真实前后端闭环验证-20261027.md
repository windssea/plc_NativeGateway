## 3. 本轮发现并修正的问题

1. **Hub概览把缺少运行态数据误显示为已停止。** `PlcMemoryPanel`现在区分缺失与真实停机；缺少LED运行态时显示“未知”。管理连接不可用的说明也改为连接范围的提示，避免MQTT在线采集却被概览泛称设备离线。中/英/德文同步；`npm run build`通过，真实页面确认修复。未伪造RSC连接成功或RUN状态，MQTT状态仍独立显示。
2. **新现场辅助脚本的退出排空曾读取缓存0值。** 正常关闭又持久保存了最后4批，未丢弃；原记录保留。未覆盖SQLite备份，改为查询真实现有存储并等待入口/选择/工作线程持续空闲2秒，关闭后再检查持久批次。通过下一次正常Agent启动、真实授时/ACK完成排空后，才恢复原SQLite。是测试辅助脚本修正，不把它误报为Outbox产品丢数。

发布期间页面先显示等待确认、随后APPLIED，查询状态需要等待实际ACK和页面刷新；没有以MQTT发送成功代替应用成功。本次未优化配置确认耗时或宣称满足延迟SLA。
