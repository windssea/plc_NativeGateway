## 实现与边界

- [NG_ReportPolicy](../src/NG_ReportPolicy.st) 每扫描至多决定 64 个不可变入口事件。cyclic 使用实际名义轮询槽；首次、质量变化、严格大于 deadband 和 bool 变化遵循共同规则。周期游标在资格决策时推进，值/质量基准只在 RAM 接纳成功后推进。RAM 原子接纳就是本模式的本地提交边界，基准保存最新 sampleSeq 的副本，交付/ACK 不回退基准。时间无效事件独立计 L，恢复只重建新采样基准和网格，旧 P 不回填、不清空。
- [NG_CaptureTypes](../src/NG_CaptureTypes.dt) 复用 28800 条池及索引，两个链式 FIFO 保存历史/新数据；引用由入口转交到池，再转交冻结批次。槽位代际和记录代际同时核对。四个配置字典按引用保留原 gateway/captureBoot/config/点映射；普通配置切换不清已接纳历史，未接纳的撤销任务明确记 VERSION_DISCARD/undecidedLost。采样配置 v4 文件格式与旧 v1 报文不变。
- [NG_BatchBuilder](../src/NG_BatchBuilder.st) 每扫描编码至多 4 个值，同点后续事件另起 messageId，批内单一配置/类别、点位唯一。最多 64 值；每次追加前将逗号、完整头和 `]}` 一并计长，整包不超过 STRING[16380]。冻结后保留原字节和 SHA-256。准备期间门槛关闭则按原顺序退回 FIFO，恢复重新准备，已接纳事件仍为 P。
- [NG_BufferMaintenance](../src/NG_BufferMaintenance.st) 按每次 DATA 门槛重开时的**已接纳水位**划分历史/新数据。物化交替，单类最多占 7 个活跃物化槽，16 个槽共享死信空间；发送总在途最多 8 批，单类最多占 7 个首次发送信用，为另一类留出机会。类内选最早可发送项，等待/退避不阻塞后续可发送项。
- [NG_Delivery](../src/NG_Delivery.st) 校验冻结摘要、messageId、批次代际、记录代际和所有者后才开放发送或处理 ACK。第一次 SDK 提交后等待 30 秒，之后 60 秒，按槽增加小幅错峰；可重试 REJECTED 只延长等待。重连不清 attempts/退避/全局限速。所有 DATA 尝试间隔至少 334 ms，约每秒 3 批；重试同样计入。PUBACK 只完成传输，不释放记录。
- [NG_EndBatch](../src/NG_EndBatch.st)、[NG_PruneTerminal](../src/NG_PruneTerminal.st)、[NG_GapLog](../src/NG_GapLog.st) 对整批进行原子所有权校验和终态记账。从未提交 SDK 的容量/900 秒单调年龄淘汰为 L；已提交、未确认而本地放弃为 U；永久 REJECTED 为 I。死信至多 4 个完整 payload/64 KiB、600 秒，超限转入有界终态关联并修剪。64 个 tombstone 仍共享记录池，保存原批摘要、代际及精确采样引用；U 的迟到 STORED 仅在关联尚存时转 S，累计 U 不减、lateStored 增加，重复 ACK 不再增加。I 与 STORED 冲突仅记录核查，不自行改判。
- 硬满池先修剪终态证据，再按最旧所有者淘汰记录或整批。若回收一个已发送批次后仍需释放其终态证据，明确累计 tombstonePruned/detailTruncated，不能承诺该批之后还能对账；事件的累计 U/I 保留。Main 的原始入口在下一次有界本地回收前可暂缓决定，不等待 SDK/ACK；首次接纳明确拒绝的单元路径仍单独计 enqueueRejectedAttempts 和 L。缺口明细最多 64 条，不用范围冒充完整事件集合。
- [Main](../src/Main.st) 已移除 latest 扫描选择/组包路径。`Samples[]` 只作实时视图；入站 ACK 不依赖 DATA 门槛，历史发送不依赖当前 Active.enabled 或新 GOOD。身份变更不能再清空 RAM 队列后复用 boot/sequence，本阶段拒绝在线 gatewayId 换绑并提示受控维护；同身份的 broker 设置仍可保存。计数在同一 boot 内不因重连/版本变化清零，安全整数饱和置 counterOverflow。

当前仍为 SYSTEM_RTC_COMPAT_UNVERIFIED，不是平台授时已实现。当前合法系统 UTC 通过兼容路径接纳；timeValid 不伪装为平台 SYNCED。TimeProvider/session 令牌和真正时间失效竞争的线上接入属于阶段 2，本次以冻结时间快照及关闭 DATA 门槛的隔离向量验证所有权行为。历史年龄仅在本进程使用单调时钟，RAM 不跨重启恢复。

## 完整程序与真实 Hub 回执

沿用当前唯一后端、前端、broker 和现有开发数据库，未创建数据库。PLC 使用原有配置 13/50 台逻辑 Modbus 模拟从站/250 点；下载前先 RAM 暂停旧程序采集并排空原业务队列。隔离夹具运行完成后再下载完整候选，候选 boot 为 `ng-d4f61b3085b97c5e3831983b-27`。

[完整候选开始快照](../tests/validation/p03-p04/plc-candidate-start.json)、[暂停并排空快照](../tests/validation/p03-p04/plc-candidate-drained.json)、[被动 wire 原文](../tests/validation/p03-p04/native-real-wire.json)及[独立汇总](../tests/validation/p03-p04/real-wire-summary.json)给出：

- 40 个不同 DATA、40 个真实匹配 STORED，2500 个值，其中 UNKNOWN 250、GOOD 2250；所有批内点位唯一，最大报文 9490 B，原文 SHA-256 全部可复核，无记录器截断。
- 暂停后本地 captured=eligible=storedConfirmed=2500，owned/ingress/批次均为 0；入口溢出、undecidedLost、timeInvalid、L/I/U、missedPoll/missedReport、接纳拒绝均为 0，HMI InvalidAcks=0。
- 暂停前尾部 546 条，在约 10.32 秒内通过真实 STORED 排空。两个运行快照之间的本地确认释放约 53.9 条/秒；这只是短窗口，**没有达到 C04 所列 90 条/秒放行目标的证据**，不能据此沿用五分钟积压的排空时限。P06 必须测量、定位并验证编码/摘要/ACK 路径吞吐与任务预算，再重算恢复峰值及年龄余量。

上述是完整实际程序的短时闭环，不是 A07 的 30 分钟、A08 的 300 秒故障或独立采集入口审计通过。尚未实现 P05 的持续 sampleSeq→messageId/值序号关联导出，不能只凭 2500 个计数和图表宣称任意故障下历史完整。
