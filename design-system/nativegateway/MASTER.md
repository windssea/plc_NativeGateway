# NativeGateway 原生操作界面

适用栈：PLCnext Engineer HMI XML + IEC/ST，1280 × 1000 原生画布，浏览器等比缩放。不是通用 HTML 应用。保留官方画布控件、输入焦点与按钮按下反馈，无外网字体或脚本。

设计依据：ui-ux-pro-max 的 Minimalism & Swiss Style 与字体层级建议适合本工业工具；搜索返回的营销页 Hero/CTA 布局不适用，未采用。工业 product 搜索两次无匹配，信息架构采用任务流程与现有工程约束。品牌色以用户提供图片为准。

- 白色卡片、浅灰绿背景；正文 #202629，次要文字 #526365。
- 青绿 #007D80 为主要按钮，白字；亮绿 #8AC640 作品牌与按下反馈，配深字。
- 原始 Phoenix Contact 图片原比例展示，不重绘标志。
- 三个主入口：设备与点位、连接设置、使用说明。当前入口使用选中样式。
- 优先设备名、点位名、数值与状态；唯一标识放在详情。
- 平台模式：设备点表只读，说明去 Hub 发布；独立模式：编辑→保存草稿→检查→使配置生效并持久化。
- 放弃草稿、删除内容、改变 broker 连接都有明确独立确认页。实时运行状态与最近操作消息分离。
- 所有按钮保留文字，44 逻辑像素高；仅有一个组合可见性条件，防止隐藏规则相互覆盖。
- 页面所有固定文案双语；业务状态以显示函数翻译，不改变协议字段、配置 ID 或用户自定义名称。语言当前为控制器界面会话级，重启默认中文。
- 本原生画布为桌面/平板维护页。窄屏采用 Engineer 等比缩放；不声称原生手机重排或完整屏幕阅读器语义。
